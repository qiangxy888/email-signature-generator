# Email Signature Generator

## What
Free tool to create professional HTML email signatures. User fills info → picks a template → copies HTML signature.

## Target Keywords
- "email signature generator" — ~40K monthly searches
- "email signature template" — ~20K
- "free email signature generator" — ~15K
- CPC: ~$3-5

## Tech
- Next.js 14 + Tailwind CSS + shadcn/ui
- Client-side only (no backend)
- Deploy to Vercel

## Pages
1. Landing page with live preview
2. Template gallery (6-8 templates)

## Form Fields (left side, live preview on right)
- Full name
- Job title
- Company name
- Phone number
- Email
- Website URL
- LinkedIn URL (optional)
- Twitter/X handle (optional)
- Profile photo URL (optional)
- Company logo URL (optional)
- Brand color (color picker, default #2563EB)

## Templates (6 styles)
1. Minimal — Name, title, contact links in one line
2. Professional — Photo + info block, divider line
3. Modern — Colorful accent bar, icons for social
4. Corporate — Logo + structured layout
5. Creative — Bold colors, unique layout
6. Simple Text — Plain text, no images (for strict email clients)

## Output
- Live preview updates as user types
- "Copy to Clipboard" button (copies rich HTML)
- "Copy HTML Code" button (raw HTML for developers)
- Instructions for Gmail, Outlook, Apple Mail

## SEO
- Title: "Free Email Signature Generator — Professional Templates"
- Rich snippets / FAQ schema
- Template gallery pages for additional SEO

## Design
Modern, clean. Split screen: form on left, live preview on right.
